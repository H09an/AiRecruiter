Тестировщик (фикстура без зарплаты)

Описание тестовой вакансии без указанной зарплаты и без блока условий. Текст нужен только для проверки парсера.

Требования

  • Понимание жизненного цикла разработки и роли тестирования в нём.
  • Навык написания понятных баг-репортов на русском языке.

Обязанности

  • Тестировать новые сценарии и поддерживать регрессионный набор.
  • SQL
  • REST API
