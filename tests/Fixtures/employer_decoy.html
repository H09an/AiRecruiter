Тестировщик (фикстура: employer без ссылки)

Вымышленная компания без ссылки
Приманка: декой-ссылка вне блока компании

Синтетическая вакансия для проверки случая, когда у элемента компании нет ссылки, а в документе есть только посторонние ссылки на employer. employer_id должен остаться пустым, данные вымышлены.
