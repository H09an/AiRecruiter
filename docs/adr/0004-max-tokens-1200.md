# 0004. MaxTokens = 1200

## Статус

Принято, реализовано частично.

## Дата

2026-11-17 для значения 800 (коммит [67a4baa](https://github.com/H09an/AiRecruiter/commit/67a4baa)); значение 1200 — не проверено.

## Контекст

Комментарий анализа ограничен 800 символами. Было решено поднять `MaxTokens` до 1200, чтобы усечённый JSON-ответ не ломал разбор. Критерий пересмотра: если `completion_tokens` стабильно ниже 600, значение пересматривается.

## Решение

`GigaChat:MaxTokens = 1200`; при `completion_tokens` ниже 600 — пересмотреть значение.

Текущее состояние кода:

- код по умолчанию использует 800 — [JobAnalyzer.cs:102](../../src/AiRecruiter/Analyzers/JobAnalyzer.cs#L102);
- 1200 задан в конфигурации — [appsettings.example.json](../../appsettings.example.json);
- поля `usage` и `completion_tokens` из ответа GigaChat не читаются, критерий пересмотра не измеряется.

## Последствия

Для кода:

- без конфигурации работает 800 — усечённый JSON возможен; в конфигурации по умолчанию репозитория значение 1200 применено.

Что ещё не сделано:

- чтение `usage` / `completion_tokens` и измерение критерия пересмотра.
