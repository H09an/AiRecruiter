# 0007. Порог оценки и shadow mode

## Статус

Заменено ADR-0009

## Дата

2026-11-17 (коммит
[67a4baa](https://github.com/H09an/AiRecruiter/commit/67a4baa)).

## Контекст

Порог отправки в Telegram нельзя зафиксировать заранее: без данных калибровки
любое значение — догадка. Если поставить жёсткий фильтр сразу, Telegram
останется пустым и исправить это будет не на чем. Решение записано в
[AGENTS.md, раздел «Оценка и фильтры»](../../AGENTS.md#оценка-и-фильтры).

## Решение

Порог `Analyzer:MinScore = 7`. Shadow mode на старте: анализируются все
вакансии, в Telegram отправляются только те, чья оценка не ниже порога;
остальные пишутся в лог и в БД.

Текущее состояние кода:

- чтение порога — [Program.cs:201](../../src/AiRecruiter/Program.cs#L201);
- оценка ниже порога → статус `analyzed_low`, в Telegram не отправляется —
  [Program.cs:411-437](../../src/AiRecruiter/Program.cs#L411-L437);
- оценка не ниже порога → статус `analyzed_ok` и отправка —
  [Program.cs:438-473](../../src/AiRecruiter/Program.cs#L438-L473).

## Последствия

Для кода:

- низкие оценки попадают в БД, порог калибруется по данным, а не по догадкам;
- в Telegram не попадают вакансии ниже порога, что осознанно принято на старте.

Что ещё не сделано:

- порог и стоп-лист фиксируются после 1–2 недель прогонов калибровки (этап 3.2).
