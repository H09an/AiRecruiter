# 0007. Порог оценки и shadow mode

## Статус

Заменено ADR-0009

## Дата

2026-11-17 (коммит [67a4baa](https://github.com/H09an/AiRecruiter/commit/67a4baa)).

## Контекст

Порог отправки в Telegram нельзя зафиксировать заранее: без данных калибровки любое значение — догадка. Если поставить жёсткий фильтр сразу, Telegram останется пустым и исправить это будет не на чем. Решение записано в [AGENTS.md, раздел «Оценка и фильтры»](../../AGENTS.md#оценка-и-фильтры).

## Решение

Порог `Analyzer:MinScore = 7`. Shadow mode на старте: анализируются все вакансии, в Telegram отправляются только те, чья оценка не ниже порога; остальные пишутся в лог и в БД.

Текущее состояние кода:

- чтение порога — [Program.cs:222](../../src/AiRecruiter/Program.cs#L222);
- оценка ниже порога → статус `analyzed_low`, в Telegram не отправляется — [Program.cs:398-419](../../src/AiRecruiter/Program.cs#L398-L419);
- оценка не ниже порога → статус `analyzed_ok` и отправка — [Program.cs:420-450](../../src/AiRecruiter/Program.cs#L420-L450).

## Последствия

Для кода:

- низкие оценки попадают в БД, порог калибруется по данным, а не по догадкам;
- в Telegram не попадают вакансии ниже порога, что осознанно принято на старте.

Что ещё не сделано:

- порог и стоп-лист фиксируются после 1–2 недель прогонов калибровки (этап 3.2).
