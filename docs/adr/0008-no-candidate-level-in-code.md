# 0008. Уровень кандидата не передаётся в код

## Статус

Принято.

## Дата

2026-11-17 (коммит
[67a4baa](https://github.com/H09an/AiRecruiter/commit/67a4baa)).

## Контекст

Числовые потолки по уровню (например, «не выше middle») в C# дублируют суждение,
которое должна делать модель, и не учитывают содержание конкретных ролей.
Единственный источник правды — `candidate_summary.md`. Решение записано в
[AGENTS.md, раздел «Оценка и фильтры»](../../AGENTS.md#оценка-и-фильтры).

## Решение

Уровень кандидата в код не передаётся. Оценивает модель по
`candidate_summary.md`.

Текущее состояние кода:

- правило в промпте: не выводить уровень кандидата из общего стажа, использовать
  только явные факты из сводки —
  [JobAnalyzer.cs:944](../../src/AiRecruiter/Analyzers/JobAnalyzer.cs#L944);
- сводка кандидата передаётся в конструктор строкой —
  [JobAnalyzer.cs:89-92](../../src/AiRecruiter/Analyzers/JobAnalyzer.cs#L89-L92);
- конструктор анализатора не принимает уровень —
  [JobAnalyzer.cs:89-97](../../src/AiRecruiter/Analyzers/JobAnalyzer.cs#L89-L97).

## Последствия

Для кода:

- суждение об уровне — в модели, а не в числовых потолках C#;
- `middle` и `middle+` не отсекаются предфильтром: при сильном профиле кандидат
  может пройти на middle.

Что ещё не сделано:

- нечего реализовывать дополнительно: решение уже в промпте; проверять его на
  данных калибровки.
