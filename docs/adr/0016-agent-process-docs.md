# 0016. Канон документов процесса агентов

## Статус

Принято. Заменяет частично [ADR-0015](0015-protocol-and-journal.md)
(раскладка документов); часть ADR-0015 о журнале решений действует.

## Дата

2026-11-26.

## Контекст

Процесс v2 вводит ростер из семи агентов вместо трёх ролей. `AGENTS.md`
вмещает протокол, стандарт документации и матрицу скиллов и приближается к
лимиту 250 строк; журналу исполнения задач (декомпозиция, отчёты ролей)
места в протоколе нет. Правила дублируются между AGENTS и скиллами.

## Рассмотренные варианты

1. Всё в `AGENTS.md`. Отклонено: лимит 250 строк, протокол растёт вместе
   с каноном и ростером.
2. Отдельный `SPEC.md`. Отклонено ранее в ADR-0015: второй обязательный
   файл усложняет запуск.
3. Раскладка: `docs/agents.md`, `docs/process.md`, `docs/documentation.md`,
   `docs/work/`. Принято.

## Решение

- `AGENTS.md` — вход: порядок чтения, preflight, роли одной строкой,
  запреты, ссылки; до 250 строк.
- `docs/agents.md` — ростер, модели и уровни, права, матрица скиллов,
  эскалация; точные права — в конфигах `.opencode/agents/`.
- `docs/process.md` — граф, профили, раунды, карточка, матрица чтения,
  артефакты (blackboard) `docs/work/`, один писатель на файл.
- `docs/documentation.md` — стандарт документации (перенос из AGENTS без
  изменения смысла), реестр фактов, лимиты строк; план этапа — roadmap,
  декомпозиция — `docs/work`, объём не меняется.
- `docs/work/_template.md` — структура артефактов; каталоги этапов
  создаются лениво на пилоте.
- Правило живёт в одном владельце; в остальных файлах — ссылка, пересказ
  запрещён. Лимиты строк проверяет `scripts/check-docs.sh` (WARNING).

## Последствия

- AGENTS короче; стандарт и матрица скиллов переехали, ссылки обновлены.
- ADR-0015 действует в части журнала решений; раскладка документов
  определяется этим ADR.
- Скиллы `stage-runbook`, `git-workflow`, `docs-quality` упоминают прежние
  роли; приведение к ростеру — при настройке процесса (roadmap, трек
  «Процесс агентов», P2).
