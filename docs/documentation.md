# Канон документов

Стандарт документации AiRecruiter (перенесён из `AGENTS.md` без изменения
смысла, ADR-0016). Вход в протокол — [`AGENTS.md`](../AGENTS.md); процесс —
[`docs/process.md`](process.md). Правило живёт в одном документе-владельце;
пересказ правила в других файлах запрещён — допускается краткая выжимка со
ссылкой.

## Реестр фактов

Один факт — один владелец; в остальных документах — ссылка.

| Факт | Владелец |
|---|---|
| запуск, настройка, конфигурация | `README.md` |
| что изменилось по этапам | `CHANGELOG.md` |
| текущее состояние кода: поток, модули, статусы, схема | `docs/architecture.md` |
| план этапов, границы, DoD, риски, трек процесса | `docs/roadmap.md` |
| процессные решения без ADR | `docs/decisions.md` |
| почему решено так | `docs/adr/` |
| вход в протокол, запреты, preflight | `AGENTS.md` |
| ростер, модели, права, матрица скиллов | `docs/agents.md` |
| граф, профили, раунды, артефакты | `docs/process.md` |
| стандарт документов, реестр, лимиты | `docs/documentation.md` |
| структура артефактов этапа | `docs/work/_template.md` |
| журнал исполнения задачи | `docs/work/<этап>/` (один писатель на файл) |

## План и декомпозиция

- План этапа — только `docs/roadmap.md`; декомпозиция — `docs/work/`;
  объём этапа при декомпозиции не меняется. Новая работа — через изменение
  roadmap владельцем, не через задачу.
- Удаление плана допускается только как «отклонено» с причиной; потерянных
  планов нет. Текущее расхождение — `docs/architecture.md`.

## Стандарт документации

- Формат: CommonMark, UTF-8, LF, один H1 вне блоков кода, ATX-заголовки;
  пустая строка вокруг заголовков, списков, таблиц и блоков кода.
- Перенос: текст и пункты списков — до 80 символов; таблицы, код, ссылки и
  URL не переносятся.
- Владение фактом — по реестру выше. Один факт — один владелец; в других
  документах — краткая выжимка со ссылкой.
- CHANGELOG — Keep a Changelog 1.1.0: `[Unreleased]`, категории `Добавлено`,
  `Изменено`, `Устарело`, `Удалено`, `Исправлено`, `Безопасность`; изменения
  документации — в `Изменено` с префиксом `Документация:`.
  - `Документация:` — изменены только файлы документации: `README.md`,
    `AGENTS.md`, `CHANGELOG.md`, `SECURITY.md`, `docs/`. Если менялись код,
    `.opencode/`, `scripts/`, CI или тег — метка не ставится, пишется обычный
    пункт.
  - Правило действует для `[Unreleased]` и будущих версий; вышедшие версии
    не переписываются.
- ADR — `Статус`, `Дата`, `Контекст`, `Решение`, `Последствия`;
  `Рассмотренные варианты` — необязательный раздел. Принятое не
  переписывается, а заменяется новым ADR.
- README — что делает, требования, установка и быстрый старт, конфигурация,
  запуск, файлы, диагностика, тесты, разработка, безопасность, лицензия.
- architecture — только текущее состояние: поток, модули, статусы, схема,
  известные расхождения; планов нет.
- roadmap — этап, статус, цель, что входит/не входит, зависимости, DoD,
  риски; статусы `planned` / `in progress` / `done`.
- Сложный шаг roadmap может иметь подраздел «Шаг N — детали»; он не заменяет
  DoD.
- AGENTS — протокол для агентов: вход, роли, запреты, документация и скиллы;
  журнал решений — `docs/decisions.md`. Текущее состояние здесь не
  дублируется; планы ссылаются на roadmap.
- Полнота: команды выполнимы, значения по умолчанию и пути указаны,
  утверждения проверяемы; отсылок к чату нет.

## Лимиты строк

`scripts/check-docs.sh` предупреждает (WARNING) при превышении:

| Документ | Лимит |
|---|---|
| `AGENTS.md` | 250 |
| `docs/agents.md` | 200 |
| `docs/process.md` | 220 |
| `docs/documentation.md` | 110 |
| `docs/adr/*.md` (каждый) | 60 |
| `docs/work/_template.md` | 60 |

Превышение — повод сократить документ или вынести факт владельцу, а не
отключить проверку.
